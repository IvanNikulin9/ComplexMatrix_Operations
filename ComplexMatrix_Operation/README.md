## Описание

Класс для работы с матрицами комплексных чисел.
Реализованы операции:

- Сложение матриц
- Умножение матриц
- Деление матриц (поэлементное)
- Транспонирование
- Вычисление определителя

К классу прилагается консольный интерфейс, позволяющий:

- Создать матрицы A и B
- Выбрать операцию из меню
- Выполнять операции многократно без перезапуска программы

## Математические формулы

### Умножение комплексных чисел

Для двух комплексных чисел `z₁ = a + bi` и `z₂ = c + di`:

```
z₁ · z₂ = (a·c − b·d) + (a·d + b·c)i
```

**Пример:**
```
(1 + 2i) · (3 + 4i) = (1·3 − 2·4) + (1·4 + 2·3)i
                   = (3 − 8) + (4 + 6)i
                   = −5 + 10i
```

### Деление комплексных чисел

Для двух комплексных чисел `z₁ = a + bi` и `z₂ = c + di` (при `z₂ ≠ 0`):

```
z₁ / z₂ = ((a·c + b·d) + (b·c − a·d)i) / (c² + d²)
```

**Пример:**
```
(1 + 1i) / (1 + 2i) = ((1·1 + 1·2) + (1·1 − 1·2)i) / (1² + 2²)
                    = (3 − 1i) / 5
                    = 0.6 − 0.2i
```

### Умножение матриц

Для матриц `A (m×n)` и `B (n×k)` результат `C = A · B` имеет размер `m×k`:

```
C[i][j] = Σ A[i][t] · B[t][j]   для t = 0..n-1
```

### Определитель

Определитель вычисляется **рекурсивно** через разложение по первой строке:

```
det(A) = Σ (−1)^j · A[0][j] · det(minor_j)
```

где `minor_j` — матрица, полученная вычёркиванием строки 0 и столбца `j`.

Базовые случаи:
- `det([a]) = a`
- `det([[a, b], [c, d]]) = a·d − b·c`

## Корректный ввод данных

**Программа использует `Scanner`, который читает токены, а не строки.**

Это значит, что при **неаккуратном вводе** некоторые символы могут **остаться в буфере** и быть использованы там, где не должны (например, как ответ на следующий вопрос меню).

### Как вводить данные правильно

1. **Размеры матрицы** — целые числа:
   ```
   Строк: 2
   Столбцов: 2
   ```

2. **Комплексные числа** — два числа через пробел (действительная и мнимая часть):
   ```
   Элемент [0][0]: 1 0
   Элемент [0][1]: 2 3
   ```

3. **НЕ нажимайте Enter внутри одного комплексного числа.** Вводите оба числа **на одной строке**.

4. Если случайно нажали Enter — программа может «съесть» следующее число как мнимую часть.

### Пример корректного ввода

```
2 2
1 0
0 0
0 0
1 0
2 2
2 1
0 0
0 0
3 -1
1
```

### Что произойдёт при ошибке

Если ввести, например:
```
Элемент [0][0]: 6
[Enter]              ← случайно
6 0
```
Тогда `6` из первой строки станет **действительной** частью, а `6` из второй — **мнимой**. Лишний `0` останется в буфере и может быть прочитан как **ответ на следующий вопрос меню** — программа «сама» завершится.

**Это не баг программы, а особенность `Scanner`.**
